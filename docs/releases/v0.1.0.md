# 0.1.0

បណ្តុំ patch Morphe ដំបូងសម្រាប់ repo នេះ — Gemini + Google app clone ដំណើរការជាមួយ microG
ដោយមិនចាំបាច់ទាញយក Google app ពី Play Store។

## Patch ទាំង 10 (default=true)

**Google app (`com.google.android.googlequicksearchbox` → `.morphe`)**
- Google App Manifest Tweaks — ឈ្មោះ `Google (Morphe)`, MicroG visibility, ដក Split constraint, បិទ crash receiver
- GmsCore Bytecode Redirect (MicroG RE 7.1.2)
- GmsCore Signature and Availability Bypass
- MicroG Account Permissions
- Google App Package Clone Support
- Process Name Spoofing for Clone Support
- Bypass Work Profile Gemini Restriction
- Allow Work Profile Gemini Eligibility

**Gemini launcher (`com.google.android.apps.bard` → `.morphe`)**
- Gemini App Manifest Tweaks — ឈ្មោះ `Gemini (Morphe)`, MicroG visibility, ដក Split constraint, បិទ crash receiver
- Gemini Redirect to Cloned Google App
